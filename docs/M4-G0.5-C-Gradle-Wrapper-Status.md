# M4-G0.5-C Gradle Wrapper Status

## Current state

The Android project skeleton contains:

- gradle-wrapper.properties
- gradlew
- gradlew.bat

## Pending

The binary file below is still required for a fully portable Gradle Wrapper build:

```
gradle/wrapper/gradle-wrapper.jar
```

After adding the generated official Gradle wrapper jar, GitHub Actions can run:

```
./gradlew assembleDebug
```

and verify the first Android debug APK build.

## Constraint

The wrapper jar is a generated binary artifact and should be produced by the Gradle wrapper task, not manually recreated.
