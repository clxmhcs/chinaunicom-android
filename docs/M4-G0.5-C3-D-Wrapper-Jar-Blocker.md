# M4-G0.5-C3-D Wrapper Jar Blocker

## Current state

The Android migration branch contains Gradle wrapper configuration files but requires the official Gradle wrapper binary before running a reproducible build.

## Missing file

```
gradle/wrapper/gradle-wrapper.jar
```

## Required action

Generate with official Gradle tooling:

```bash
gradle wrapper --gradle-version 8.10.2
```

Then commit the generated binary and run:

```bash
./gradlew assembleDebug
```

## Acceptance

Expected:

```
BUILD SUCCESSFUL
```

and debug APK output under:

```
app/build/outputs/apk/debug/
```
