# Android-M0 Manifest Templates

## IOS_SOURCE_MANIFEST

Record Swift source files and Android target modules.

Format:

| iOS File | Purpose | Android Target |
|---|---|---|
| | | |

## API_MANIFEST

Record:

- Endpoint
- HTTP method
- Headers
- Parameters
- Cookie/token requirements
- Response model
- Error codes

## MODEL_MANIFEST

Record:

- Swift struct/enum
- Kotlin data class/enum
- Serialization rules

## STORAGE_MANIFEST

Record:

- Keychain usage
- Local persistence
- Cache behavior
- Cloud storage dependency
- Android replacement strategy

## SCREEN_MANIFEST

Record:

- Screen name
- Entry point
- Data source
- State owner
- Android Compose target

## VISUAL_BASELINE

Record:

- Screenshot
- Light mode reference
- Dark mode reference
- Colors
- Spacing
- Typography
- Corner radius
- Component behavior
