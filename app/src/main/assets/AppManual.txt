# 联通余量 Android App 使用说明书

**适用项目：** `clxmhcs/chinaunicom-android`
**最低系统：** Android 11 / API 30
**主要用途：** 中国联通多号码余量、话费及相关业务查询与管理

本说明书依据当前 Android 已迁移功能整理。界面仍处于“业务功能优先、最终视觉精修后置”阶段；桌面 Widget 主体属于 Android-M12，抓包工具主体属于 Android-M14，因此本版本只提供它们的设置配置或入口说明，不把尚未实现的主体能力描述为已可用。

---

# 一、App 功能概览

当前 App 有五个主页面：

1. 流量
2. 语音
3. 综合业务
4. 其它业务
5. 设置

当前已迁移的主要业务包括：

- 多手机号码管理
- 独立宽带号码管理
- 流量余量与语音余量
- 账户余额
- 已订业务
- 我的套餐
- 我的订单
- 话费 / 账单
- 积分
- 返费 / 赠费
- 视频彩铃会员
- 电子受理单
- 资费专区
- 附近营业厅
- 设置与刷新策略

---

# 二、第一次使用

## 2.1 添加手机号码

进入：

**设置 → 数据与安全 → 凭据信息新增 / 编辑**

手机号码优先使用短信验证码登录。账号验证成功后，普通账号元数据与敏感登录凭据分别保存。

Cookie、appID、token_online 等敏感凭据不会写入普通账号展示数据。

## 2.2 添加独立宽带

独立宽带同样从凭据管理页面添加。

宽带账号在保存前必须通过真实联通余量请求验证。宽带普通元数据与敏感凭据分离保存，并且不会被插入首页的手机流量/语音账号列表。

---

# 三、流量页面

流量页使用已保存且启用的手机号码。

每张号码卡片可显示：

- 套餐或资源信息
- 流量已用 / 剩余
- 余额
- 更新时间
- 刷新状态或错误状态

账号排序来自设置中的“账户卡片排序”，刷新全部号码也沿用同一顺序。

---

# 四、刷新单个号码与刷新全部

单号码刷新只刷新所选号码。

刷新全部按账号排序依次处理，并遵守 App 刷新逻辑中的最小刷新间隔、前台检查和账号间隔等设置。

凭据失效时，已有会话恢复逻辑会尝试更新当前账号凭据；更新后的凭据仍写回本机安全凭据存储。

---

# 五、语音页面

语音页与流量页共用同一生产账号状态。

语音页展示当前账号可见语音资源，不建立第二套账号或刷新 authority。

---

# 六、综合业务

综合业务复用已经迁移的业务 Store / Cache / Refresh authority，主要包括：

- 已订业务
- 话费 / 账单
- 流量余量详情
- 语音余量详情
- 积分

综合业务不通过重新联网来伪造独立数据源，而是按各业务既定刷新和缓存合同工作。

---

# 七、其它业务

其它业务当前包括：

- 已订业务
- 视频彩铃会员
- 电子受理单
- 我的订单
- 我的套餐
- 积分
- 话费 / 账单
- 返费 / 赠费
- 资费专区
- 附近营业厅

各业务是否支持独立宽带，以具体业务的源逻辑为准；不会为了统一界面而把宽带强行加入只支持手机号码的业务。

---

# 八、已订业务

已订业务复用现有 OrderedBusiness Store。

支持手机号码；源逻辑允许的独立宽带目标也使用同一业务 Store，不建立重复网络栈。

---

# 九、我的套餐

我的套餐支持已保存手机号码与独立宽带目标。

手机号码默认进入移网资源；独立宽带默认进入宽带资源。

如联通接口需要短信验证才能返回完整成员号码，App 不会绕过该运营商验证要求。

---

# 十、我的订单

我的订单支持真实运营商订单列表、刷新、搜索、筛选与分页。

某些订单没有可用详情时会显示“暂无可用详情”，不会虚构详情地址或内容。

---

# 十一、话费 / 账单

账单保留当前月与历史月不同缓存策略。

合账组只显示一个财务代表号码时，代表号码由设置中的现有 BalanceRepository authority 决定，而不是在账单页单独保存另一份映射。

---

# 十二、余额与合账

进入：

**设置 → 合账号码选择**

同一个号码只能属于一个合账组。只有至少两个有效成员时，组才按合账组参与余额刷新。

进入：

**设置 → 余额 / 账单 刷新号码编辑**

可设置：

- 首页余额显示 / 刷新号码
- 每个有效合账组的默认财务代表号码

这些设置共同复用现有 BalanceRepository。

---

# 十三、积分

积分使用独立积分缓存与刷新策略。

设置中的 App 刷新逻辑可编辑：

- 是否自动刷新
- 刷新周期模式
- 月度日期 / 时间
- 固定间隔
- 进入页面检查

---

# 十四、返费 / 赠费

返费 / 赠费支持合约返赠和赠款记录。

设置中的刷新策略可控制月度自动刷新日期、时间以及无缓存时是否立即查询。

---

# 十五、视频彩铃会员

视频彩铃只使用已保存且启用的手机号码。

登录返回的 caller 必须与当前选择号码一致，否则 App 会拒绝展示该会话返回的会员数据，防止跨号码串号。

当前源逻辑中的权益页面以读取 / 展示为主，App 不会虚构领取或兑换接口。

---

# 十六、电子受理单

电子受理单支持：

- 手机号码与源逻辑允许的宽带目标
- 激活当前目标登录态
- 打开联通电子受理单页面
- 识别 PDF
- 保存到 App 私有目录
- 选择外部 PDF 导出目录
- 导出与删除本地受理单

进入：

**设置 → 数据与安全 → 电子受理单保存目录**

Android 使用系统目录选择器保存持久目录权限。即使设置了自动导出目录，PDF 仍会先保存到 App 私有受理单存储。

---

# 十七、资费专区

资费专区使用本地原生页面接入已迁移业务逻辑，不以虚假静态内容代替真实数据路径。

---

# 十八、附近营业厅

附近营业厅按当前已迁移的营业厅业务逻辑工作。

位置权限、定位服务或运营商数据不可用时，应以实际错误 / 空状态为准。

---

# 十九、显示设置

设置页当前支持：

- 隐藏手机号中间四位
- 宽带号码只显示前后四位
- 流量显示单位
- 账户卡片自定义排序
- 号码归属纠正

号码脱敏设置只影响显示，不会改写真实账号号码。

---

# 二十、号码归属纠正

“号码归属纠正”只修正 App / Widget 的运营商显示。

它不会改变：

- 登录账号
- 网络查询号码
- 刷新目标
- 套餐数据
- CredentialStore 绑定关系

可选择自动识别、联通、移动、电信、广电或其它。

---

# 二十一、运营商号段

设置页可更新并查看本机已保存的运营商号段。

号段更新失败时，App 会保留或回退到源码内置的基础运营商号段，不应因此影响正常联通业务查询。

---

# 二十二、每日用量基准

每日用量基准按：

**账号 UUID + 日期**

独立存储。

设置页只负责查看，不会在白天发现基准缺失时擅自补写一个“伪午夜基准”。

同日派生的今日流量用量缓存采用单调最大值，避免运营商累计计数回退造成今日用量倒退。

---

# 二十三、App 刷新逻辑编辑

当前统一刷新设置文档覆盖：

- 流量 / 语音
- 余额
- 已订业务
- 我的套餐
- 话费 / 账单
- 积分
- 我的订单
- 返费 / 赠费
- 视频彩铃
- Widget 刷新策略

这些设置写入同一 AppRefreshLogic schema-3 authority，不建立并行刷新设置文件。

---

# 二十四、单号码 Widget 配置

设置页可提前配置 M12 Widget 将使用的：

- 号码
- 是否显示今日用量
- 是否显示余额
- 六个资源位置
- 每个位置的显示开关、类型与资源绑定

当前 M11 只完成配置 authority 与编辑页面；Android 桌面 Widget 主体在 M12 实现。

---

# 二十五、双号码 Widget 配置

双号码配置保存左、右两个号码以及每侧六个位置。

左右号码不能相同。

每个位置可配置：

- 流量
- 语音
- 可用积分
- 显示 / 隐藏
- 统计分类或具体资源绑定

积分位置固定读取 App 缓存数据。

---

# 二十六、Widget 刷新策略

Widget 刷新策略与 App 刷新逻辑使用同一 schema-3 设置 authority。

默认刷新时间为：

- 08:00
- 11:00
- 14:00
- 17:00

默认补偿窗口 6 分钟，默认失败重试 30 秒。

真实 Android Widget 调度在 M12 接入。

---

# 二十七、快捷通知设置

快捷通知配置按账号 UUID 独立保存。

支持 A / B / C / D 通知槽位，并可设置：

- 是否通知流量
- 是否通知语音
- 是否通知余额
- 查询失败是否通知
- 标题模板
- 副标题模板
- 正文模板

同一 A/B/C/D 槽位不会同时分配给两个账号。

快捷通知普通配置不包含 Cookie、appID、token_online 等敏感凭据。

---

# 二十八、凭据安全

敏感账号凭据由已有本机安全 CredentialStore 管理。

普通业务状态、Widget 配置、号码归属修正、快捷通知模板等配置不得复制保存敏感 Cookie、token_online、appID 或身份验证数据。

---

# 二十九、抓包工具

设置中提供抓包工具迁移入口。

Android 的 VPN、HTTPS 解密、证书与抓包会话主体属于 Android-M14。当前版本不会用一个无法真正抓包的假页面冒充完整实现。

---

# 三十、说明书查看器

本说明书查看器支持：

- 本地离线阅读
- 搜索文字
- 目录查看与章节跳转
- 继续阅读
- 中国联通水印

# 三十一、常见问题：首页没有数据

依次确认：

1. 设置中是否已经存在并启用手机账号。
2. 账号是否完成真实联通验证。
3. 是否存在刷新错误提示。
4. App 刷新逻辑是否允许当前触发方式刷新。
5. 运营商接口是否临时不可用。

不要通过反复删除凭据来掩盖网络或运营商接口错误。

---

# 三十二、常见问题：余额为什么多个号码一样

如果号码属于同一有效合账组，多个号码显示同一共享余额可能是合账设计本身。

应在“合账号码选择”和“余额 / 账单 刷新号码编辑”中确认组成员和代表号码。

---

# 三十三、常见问题：账单显示的是另一个号码

有效合账组会通过财务代表号码查询账单。

检查：

**设置 → 余额 / 账单 刷新号码编辑**

这里与账单页面使用同一 representative authority。

---

# 三十四、常见问题：Widget 现在为什么没有桌面显示

M11 只迁移 Widget 配置和刷新策略 authority。

真实 Android App Widget / Glance 主体属于 M12；完成 M12 后这些配置会被桌面组件读取。

---

# 三十五、常见问题：抓包入口为什么不能开始抓包

抓包主体属于 M14。

M11 只收口设置入口，不会提前加入不完整的 VPN / HTTPS 解密实现。

---

# 三十六、安全使用建议

- 不要截图或公开 Cookie、appID、token_online、验证码、密码、身份证信息。
- 不要把真实凭据提交到 GitHub。
- 使用系统提供的安全存储和目录授权。
- 账号出现串号迹象时不要继续展示数据，应停止并检查会话绑定。
- 运营商接口返回空数据时，不应自行伪造业务记录。

---

# 三十七、推荐使用顺序

1. 添加并验证手机账号。
2. 如有独立宽带，再单独添加宽带。
3. 调整账户卡片排序。
4. 多号码用户确认合账组。
5. 设置首页余额号码和财务代表号码。
6. 执行一次正常刷新并确认真实数据。
7. 按需要调整流量单位与号码脱敏。
8. 按需要调整 App 刷新逻辑。
9. 查看每日用量基准状态。
10. 为后续 M12 Widget 配置单/双号码信息。
11. 有电子受理单需求时选择 PDF 导出目录。
12. 按需要配置快捷通知模板。

---

# 三十八、当前版本定位

当前 Android 项目优先完成与 iOS 一致的业务数据、缓存、刷新、账号隔离和安全边界。

最终卡片样式、字体、间距、渐变、图标和页面截图级视觉对照仍按项目约定留到后续逐页面精修阶段。
